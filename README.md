# DJ Radio

DJ Radio is a 24/7 radio station that runs on your own Windows PC, from the music folder you already have. You control it from a dashboard in your browser. OBS loads a player page for the stream. Fans can get a link where they vote on the next hour’s genre, or ask for a song.

Your music folder is only read. Nothing in it is moved, renamed, or copied. Votes and settings stay on your PC.

A **$5/month key** unlocks the public vote link. The radio, the dashboard, and the OBS player all run without a key. If there is no key, or the subscription ends, only the vote link closes.

## Install

1. Download `DJ-Radio-v2i.zip` and unzip the `DJ Radio` folder anywhere (Desktop is fine).
2. Double-click **Start DJ Radio.cmd**. A black window opens and your browser opens the setup. **Leave this window open.**
3. Follow the setup screens. The last one gives you the OBS link and the vote link.

After setup, double-clicking **Start DJ Radio.cmd** opens the dashboard again.

## Stop the station

Click **Stop DJ Radio** on the dashboard, or double-click **Stop DJ Radio.cmd** in your DJ Radio folder, then close any leftover black window. You can also close the Start window. Stopping also stops OBS/player audio.
